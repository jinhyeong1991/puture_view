# Puture View - AI Image Studio

모델(Gemini / QwenCloud / OpenAI)을 고르고, 프롬프트·URL·참조 이미지를 넣어 이미지를 만드는 크롬 확장 프로그램입니다.

## 기능

- **모델 선택 카드**: 제공자별 필터(Gemini/Qwen/OpenAI), 검색, 비용·특징·검증 상태·키 등록 여부 표시
- **내 키로 사용 가능한 모델 불러오기**: 각 제공자 API에서 실제로 쓸 수 있는 이미지 모델을 조회해 목록에 추가
- **프롬프트 영역**과 **URL 영역**
  - URL이 상품 페이지면 제목·설명(또는 본문 일부)을 프롬프트에 반영하고 대표 이미지(og:image)를 참조 이미지로 사용(선택)
  - URL이 이미지 주소면 그 이미지를 참조 이미지로 사용
- 참조 이미지 최대 6장 (끌어다 놓기, 선택, Ctrl+V 붙여넣기), 이미지마다 **역할** 지정
  - **참고(인물)**: 얼굴·헤어·안경·체형을 그대로 유지할 인물/주체
  - **포즈**: 자세·손동작·각도·구도만 따라 함 (얼굴·옷·배경은 가져오지 않음)
  - **합성 재료**: 장면에 넣을 물건/요소 (모양·색·로고 유지)
  - **배경**: 이 장면을 배경으로 사용
  - **스타일·분위기**: 색감·조명·화풍만 참고
  - 생성 시 "Image 1 = 참고, Image 2 = 포즈…" 형태의 역할 안내문을 프롬프트 앞에 자동으로 붙이고(Gemini는 이미지마다 라벨도 붙임), "넣은 이미지와 어울리게 생성"을 켜면 조명·색감·원근·그림자를 맞추도록 지시합니다. 프롬프트 도우미도 역할을 알고 프롬프트를 씁니다.
  - URL 대표 이미지는 "합성 재료", 결과를 "참조로 사용"하면 "참고(인물)"로 들어갑니다.
- 화면 비율(1:1, 3:4, 4:5, 9:16, 4:3, 16:9)과 해상도/품질 선택 (제공자별로 선택지가 달라짐)
- 결과 저장, 프롬프트 복사, 결과를 참조 이미지로 다시 사용
- 모델 목록에 없으면 "직접 입력"으로 모델명 지정

## ✨ 프롬프트 도우미

이미지를 올리고 **단어만**(예: `소녀, 정수기, 냉장고`) 넣은 뒤 **형식**을 고르면, AI가 이미지를 분석해서 그 형식에 맞는 프롬프트(영어 + 한글)를 써 줍니다.

- 형식 15종: 광고 포스터, 인스타그램 피드, 인스타 스토리/릴스, 유튜브 썸네일, 가전 종합몰 상세, 책/내용 인포그래픽, 픽셀 아트, 카툰/만화, 카드뉴스, 제품 스튜디오 컷, 라이프스타일 사진, 3D 미니어처, 수채화 일러스트, 영화 포스터, 웹 배너
- AI가 본 내용(제품·인물·색·분위기) 요약, 메인 프롬프트 1개 + 변형 2개, 권장 비율 자동 적용
- 이미지에 넣을 문구를 입력하면 한 글자도 바꾸지 않고 프롬프트에 넣습니다. 문구가 필요한 형식인데 비워 두면 짧은 문구를 제안하고, 사진 형식은 글자를 넣지 않습니다.
- 옵션: "이미지를 올리면 자동으로 분석", "프롬프트가 만들어지면 바로 생성(3초 카운트다운·취소 가능, 세션당 10회 상한)"
- Gemini API 키가 필요합니다(텍스트 호출이라 1회 수 원 수준).

## 🖼 사진관 해설 · 점수 · 후속 제안 (생성 후 자동)

이미지가 만들어지면 결과 카드 아래에 다음이 붙습니다.

- **사진관 직원의 작품 해설**과 **이미지 스토리보드**(시선 흐름 4~5단계)
- **항목별 점수**(배경·인물·제품·타이포·구도·조명/색감·현실감·프롬프트 일치도, 해당 없으면 "해당 없음")와 종합 점수, 좋은 점/아쉬운 점
- **🔤 정밀 글자 검수**: 이미지 속 글자를 AI가 옮겨 적게 한 뒤 요청한 문구(따옴표 안 문구)와 코드로 비교해 오타를 표시하고 타이포 점수에 반영합니다. 작은 글자 오타를 가장 잘 잡은 `gemini-3.1-pro-preview`를 기본값으로 썼습니다.
- **Q1·Q2·Q3 후속 제안**: Q1 = 가장 약한 점 개선, Q2 = 다른 분위기/구도, Q3 = 다른 형식(스토리·썸네일·인포그래픽 등). "프롬프트에 적용" 또는 "이 방향으로 바로 생성"(비용 확인창)

점수는 AI의 판단이라 참고용입니다. 글자 검수도 완벽하지 않으니 중요한 문구는 이미지를 직접 확대해서 확인하세요.

## 지원 모델

| 제공자 | 목록의 모델 |
|---|---|
| Gemini | gemini-3.1-flash-image, gemini-3-pro-image, gemini-2.5-flash-image, gemini-nano-banana-2.1 |
| QwenCloud | qwen-image-3.0, qwen-image-3.0-pro |
| OpenAI | gpt-image-2.5-sunburst, gpt-image-2.5-flare, gpt-image-2, gpt-image-1.5, gpt-image-1-mini |

"직접 생성 성공" 배지가 있는 모델(gemini-3.1-flash-image, qwen-image-3.0/pro, gpt-image-2.5-sunburst)만 실제 호출로 확인했고, 나머지는 모델 목록에서만 확인했습니다. 모델별 파라미터가 다르면 오류 메시지가 화면에 표시됩니다.

## 설치 (개발자 모드)

1. 크롬에서 `chrome://extensions` 를 엽니다.
2. 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`puture_view`)를 선택합니다.
4. 툴바의 확장 아이콘을 누르면 작업 화면이 새 탭으로 열립니다.

## 처음 설정

**⚙ API 키 설정**에서 사용할 제공자의 키를 입력합니다.

| 제공자 | 발급처 |
|---|---|
| Google Gemini | aistudio.google.com |
| QwenCloud | home.qwencloud.com (API 주소 기본값: 싱가포르 `https://ap-southeast-1.maas.qwencloudapi.com`) |
| OpenAI | platform.openai.com |

키는 이 브라우저의 `chrome.storage.local`에만 저장되고 코드나 저장소에 포함되지 않습니다. 공용 PC에서는 사용 후 지우세요.

## 비용과 주의

- 이미지를 만들 때마다 각 제공자에게 비용이 부과됩니다. 화면의 예상 비용은 대략적인 값이며 변동될 수 있으니 각 사 요금표를 확인하세요. 결제 화면에서 월 한도와 알림도 설정해 두세요.
- 비율은 제공자 지원 크기에 맞춰 근사됩니다(예: OpenAI는 1024x1536/1536x1024, Qwen은 4:5 대신 3:4).
- 한글 문구가 들어간 이미지는 모델이 글자를 틀리게 그릴 수 있습니다. 중요한 문구는 결과를 꼭 확인하세요.
- 실존 인물·연예인 사진을 참조로 쓰지 마세요. AI로 만든 이미지를 광고 등에 쓸 때는 AI 생성 표시와 상표·초상 관련 규정을 확인하세요.
