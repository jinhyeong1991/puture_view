Puture View

모델을 고르고 프롬프트·URL·참조 이미지를 넣어 이미지를 생성합니다

1. 생성 설정

모델 선택
참조 이미지 (최대 4장, 선택)
이미지를 끌어다 놓거나 클릭해서 선택 · 붙여넣기(Ctrl+V)도 가능
실존 인물·연예인 사진은 참조로 쓰지 마세요. 본인이거나 동의받은 사진, AI로 만든 가상 인물만 사용하세요.

✨ 프롬프트 도우미

이미지를 올리고 단어만 넣은 뒤 형식을 고르면, AI가 이미지를 분석해서 그 형식에 맞는 프롬프트를 써 줍니다. (텍스트 생성 비용은 1회 수 원 수준)

형식/스타일

상품/참고 URL (선택)
PSD 레이아웃 (선택)
PSD를 넣으면 체크한 텍스트 레이어는 손대지 않고, 텍스트 밖 영역에만 제품과 배경을 만들어 원본 크기 PNG·PSD로 돌려줍니다.
0자
대표 썸네일(없으면 첫 참조 이미지)을 오려 자리를 잡아 보내고, 생성 후 원본 제품을 같은 자리에 다시 얹습니다. 흰색·투명 배경 제품 사진일 때 동작합니다.

2. 결과

왼쪽에서 모델과 프롬프트를 정하고 "이미지 생성"을 누르세요.
결과는 이 화면에만 보관되며 탭을 닫으면 사라지니 필요한 이미지는 저장하세요.

API 키 설정

키는 이 브라우저의 확장 저장소(chrome.storage.local)에만 저장되고, 해당 제공자 API 호출에만 사용됩니다. 공용 PC에서는 사용 후 지우세요.
