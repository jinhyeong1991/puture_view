모델을 고르고 프롬프트·URL·참조 이미지를 넣어 이미지를 생성합니다

1. 생성 설정

모델 선택
🔒 보호할 제품 이미지 (1장, 선택)
모양·색·로고가 절대 바뀌면 안 되는 제품 사진 · 흰 배경 사진이면 원본 그대로 합성
🎨 합성·패러디 이미지 (최대 5장, 역할 선택)
위에서 역할을 고른 뒤 끌어다 놓거나 클릭해서 선택 · 자유롭게 변형·합성됩니다 · 붙여넣기(Ctrl+V)도 가능
넣은 이미지마다 아래에서 역할을 바꿀 수 있어요. 예) 참고(내 사진) + 포즈(원하는 자세) + 합성 재료(소품) + 배경. 모양이 절대 바뀌면 안 되는 제품은 위 🔒 칸에 넣으세요. 실존 인물·연예인 사진은 쓰지 마세요. 본인이거나 동의받은 사진, AI로 만든 가상 인물만 사용하세요.

✨ 프롬프트 도우미

이미지를 올리고 단어만 넣은 뒤 형식을 고르면, AI가 이미지를 분석해서 그 형식에 맞는 프롬프트를 써 줍니다. (텍스트 생성 비용은 1회 수 원 수준)

형식/스타일

상품/참고 URL (선택)
0자
🔒 제품 이미지(없으면 URL 대표 썸네일)를 오려 자리를 잡아 보내고, 생성 후 원본 제품을 같은 자리에 다시 얹습니다. 흰색·투명 배경 제품 사진일 때 동작합니다. 🎨 합성용 이미지는 덮어씌우지 않습니다.

여러 비율 동시 생성 (선택)
체크하지 않으면 위 '화면 비율' 하나로 만듭니다. 제품 자리는 비율마다 다시 잡습니다.

2. 결과

🔍 업스케일 (고화질 확대)

확대할 이미지를 끌어다 놓거나 클릭해서 선택

왼쪽에서 모델과 프롬프트를 정하고 "이미지 생성"을 누르세요.
결과는 이 화면에만 보관되며 탭을 닫으면 사라지니 필요한 이미지는 저장하세요.

API 키 설정

키는 이 브라우저의 확장 저장소(chrome.storage.local)에만 저장되고, 해당 제공자 API 호출에만 사용됩니다. 공용 PC에서는 사용 후 지우세요.
